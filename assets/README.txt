assets/

把档案放进对应位置，页面会自动启用；没放就自动隐藏，不会破图。

1. assets/ronald.jpg      你的头像。直式 4:5（建议 900x1125），jpg。
2. assets/ambient.mp3     全站背景轻音乐（建议 2-4 分钟，会循环）。
3. assets/logos/*.png     合作品牌 logo，白色或透明底 PNG，档名要完全一样：
                          astro-shaw.png / netflix.png / gsc.png / mm2.png /
                          milo.png / nestle.png / great-eastern.png /
                          zhaochuan.png / 8tv.png / sohu.png
                          放哪个就显示哪个，没放的自动退回文字。
